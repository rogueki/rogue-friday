# Obsidian installation reuse evidence

On Windows, `installer/install-friday.ps1` invokes `setup-obsidian.ps1 -Action ensure`. The setup now validates the Friday install state before creating a vault or considering an application install. It keeps the explicit vault, then the user-selected vault, then the saved Friday vault when its `.obsidian` directory still exists. It does not select an unrelated vault by scanning the disk. The vault helper creates missing Friday folders and checks write access; it does not replace existing `.obsidian` settings or notes.

The application resolver accepts an existing `Obsidian.exe` with an `MZ` header from `FRIDAY_OBSIDIAN_APP`, per-user or system locations, `PATH`, Windows App Paths or uninstall registry entries, and the known portable path `D:\obsidian\App\Obsidian.exe`. Missing or stale entries and `Uninstall.exe` are rejected. `winget` is called only after every existing candidate fails and the installed executable is resolved again afterward. The same resolver is used on repeated runs. Both Windows updater payload lists include the setup script and its two helpers, so an incremental update carries the new decision path.

The native Linux installer has no Obsidian GUI package channel or vault installer. Its new read-only status probe recognizes an executable at a configured path, per-user/system binary locations, portable AppImage and an installed Flatpak. It reports the existing app without running an installer or modifying vault data. It does not claim to configure the Hermes vault on native Linux.

PowerShell parsed the setup and updater scripts. `installer/tests/dashboard-update-wsl-bridges.Tests.ps1` passed its verified payload/clean-install closure fixture. `installer/linux/test_find_obsidian_install.sh` and Bash syntax checks passed in isolated Ubuntu WSL. A read-only resolver call found the real `D:\obsidian\App\Obsidian.exe` (239103760 bytes); no application was launched, installed or changed. The Windows→WSL vault apply and clean Friday reinstall remain final runtime acceptance gates.
