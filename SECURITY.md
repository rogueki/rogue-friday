# Sicherheitsmeldungen

F.R.I.D.A.Y. ist eine öffentliche Beta. Melde Schwachstellen bitte über **Security → Report a vulnerability** dieses GitHub-Repositories, damit Details zunächst privat bleiben. Veröffentliche keine Zugangsdaten, persönlichen Daten oder ausnutzbaren Details in einem öffentlichen Issue.

Nenne die betroffene Version oder den Commit, die nötigen Voraussetzungen, die beobachtete Wirkung und einen möglichst kleinen Reproduktionsweg mit synthetischen Daten. Für allgemeine Fehler und Funktionswünsche sind öffentliche Issues geeignet.

Für produktive Nutzung sichere die lokale Installation, aktualisiere Abhängigkeiten und prüfe optionale Integrationen einzeln. Der Beta-Status ist keine Zusage, dass jeder Skill oder Anbieterpfad bereits live geprüft wurde.
